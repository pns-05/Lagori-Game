# Lagori Game

## Project Overview
Lagori is a traditional Indian game also known as Seven Stones. This project recreates the game as a simple digital version that can be played on a computer.

## Features
- Digital version of the traditional Lagori game.
- Simple and user-friendly interface.
- Runs as a Windows desktop application.
- Packaged as a Windows installer for easy installation.

## Technologies Used
- HTML
- CSS
- JavaScript
- Electron
- Electron Builder

## How to Run
### Option 1: Windows Installer
1. Download `Lagori Game Setup 1.0.0.exe` from the Releases section.
2. Run the installer.
3. Open Lagori Game after installation.

### Option 2: Run from Source
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser to run the browser version.

To run the desktop version from source, install Node.js and run:

```bash
npm install
npm start
```
